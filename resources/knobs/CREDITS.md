# Knob design

The knobs are redrawn from `maschine-white2096x96.knob`, KnobGallery item #1349
(https://www.g200kg.com/en/webknobman/gallery.php), licensed CC0 1.0 (public domain).
The original KnobMan file is kept here for reference; the plugin draws its layers in code
(source/PluginEditor.cpp) so they stay sharp at any size.
